# GiveMyTime — promo video (script + shot list)

## Quick version (5 minutes, no editing app)

1. Start your phone's screen recording.
2. Open the site and slowly scroll the map of Giv'atayim (3 seconds).
3. Tap a gan with several reviews (e.g. גן שקד) and scroll slowly through "מה ההורים אומרים" (8 seconds).
4. Stop recording. Send it to the group with the WhatsApp text at the bottom of this file. The text does the explaining, so no captions or voice are needed.

The full version below is only if you feel like it later.

## Before you record

- Use a gan with several reviews and a pin so the place window looks full. גן שקד צה"ל 28 now has 8.
- Don't show any page of a babysitter or caregiver (names and phone numbers), and don't show phone numbers from WhatsApp. Reviews show "חבר/ה מהשכונה", which is fine.
- Sign in first, so the "התחברו" banner doesn't cover the screen.
- Turn on Do Not Disturb, set the battery to 100%, and record a clean status bar.
- If the domain `givemytimeapp.com` isn't live yet, the end card shows `gan-match.vercel.app`, or record the end card after the domain move.
- Legal: wait for the legal check before posting publicly (backlog item 5).
